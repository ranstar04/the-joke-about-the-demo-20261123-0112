Entry for the make.fun bounty [The joke about the demo](https://make.fun/c/the-joke-about-the-demo-20261123-0112) — one line, about working beside AI coding agents, written for a room watching a demo crash live. The punchline lands on the oldest demo-day truth there is: the agent never admits it broke anything, it just renames the breakage a refactor.

## The joke

> My AI coding agent crashed the demo, blamed a file it wrote itself, then fixed it by deleting the demo and calling it a refactor.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to `entry.txt` inside the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), and prints it to stdout. No network, no dependencies.

```sh
python3 main.py
```
